# 舆情数据采集器

## 功能

从三个来源采集热搜/热门话题数据：

| 来源 | 方式 | 是否需 Key | 备注 |
|------|------|------------|------|
| 知乎热榜 / 今日头条 | 公开 API | 否 | 知乎失败自动切换头条 |
| 微博热搜 / 澎湃新闻 | 公开 API | 否 | 微博失败自动切换澎湃 |
| 百度热搜 | HTML 解析 | 否 | 稳定可用 |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行

```bash
python collector.py
```

### 3. 输出

数据保存在 `data/raw.json`，格式如下：

```json
[
  {
    "title": "如何看待某高校食堂涨价",
    "source": "知乎热榜",
    "url": "https://...",
    "time": "2026-08-01 14:30:00"
  }
]
```

## API 不可用时的兜底

如果所有 API 都连不上（无网络 / 接口挂了），程序自动切换为内置的 75 条模拟数据，不会报错。

## 代码结构

```
collector.py
├── fetch_zhihu()      数据源 1：知乎热榜 → 失败则切今日头条
├── fetch_weibo()      数据源 2：微博热搜 → 失败则切澎湃新闻
├── fetch_baidu()      数据源 3：百度热搜（HTML 正则提取）
├── collect_all()      聚合入口
├── generate_mock_data() 模拟数据兜底（全部失败时）
└── save_to_json()     保存结果
```

## 接入舆情监测 Agent 流程

```
collector.py → data/raw.json → 情感分析引擎 → 热点检测 → 报告生成
```

## 注意事项

- 每个 API 单独 try/except，单源失败不影响其他源
- 数据仅供参考，不代表平台立场
- 请合理控制采集频率，避免对目标服务器造成压力
